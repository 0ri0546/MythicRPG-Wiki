# Combat

Fighting regroupe les améliorations de mêlée, les effets appliqués à l’impact, les multiplicateurs de butin et les protections permanentes. Son arbre permet de choisir entre plusieurs branches avant de converger vers les perks finaux.

## Barons

Le code contient un catalogue important de comportements de Barons, de récompenses et d’objets légendaires. La v0.2 référence ce système et rend l’arbre complet explorable ; les fiches exhaustives des différents Barons restent prévues pour la phase de contenu suivante.

## Lecture de l’arbre

Le simulateur respecte les parents et les conflits de branche extraits du Java. Il sert à explorer un build, pas à recommander une manière optimale de jouer.
